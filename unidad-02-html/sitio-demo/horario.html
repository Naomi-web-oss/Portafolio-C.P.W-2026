Còmo entregar una practica con lista ordenada

  1. Hacer push y crear pull request
  2. Crear la rama de la practica con changes
  3. Trabajar y hacer commit
  4. Subir la rama con git push
  5. Abrir el pull request en Github
  6. Revisar y fucionar
  7. Volver a la rama principal main
  8. Eliminar la rama de la practica con git branch -d nombre de la rama

Solucionar en git con lista descriptiva

Commit
Instantanea permanente del proyecto en un momento dado
Rama
Linea de trabajo paralela que no afecta a main
Pull
Solicitud de revisiòn para incorporar una rama
